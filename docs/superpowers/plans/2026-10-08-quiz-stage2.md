# 상식 퀴즈 2단계(스피드·힌트·모드 선택·다시 풀기) 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 시작 화면에서 연습·스피드·힌트 모드를 고르고, 스피드는 문항당 15초, 힌트는 오답 2개 지우기(맞히면 0.5점), 연습은 틀린 문제만 다시 풀 수 있게 한다. 점검은 `script.js` 안의 자체 점검을 `node script.js` 한 줄로 실행한다.

**Architecture:** 1단계 구조를 유지한다. `script.js` 앞부분은 순수 함수, 가운데는 상태와 화면 함수, 그 뒤는 자체 점검(`runSelfChecks`), 맨 끝은 실행 분기다. 브라우저에서는 `initApp()`을 실행하고, Node에서는 자체 점검만 실행한다. 모드별 차이는 `MODES` 설정표에 모은다.

**Tech Stack:** HTML, CSS, 바닐라 JavaScript(모듈 없음). 개발 중 점검만 Node.js(LTS).

**Spec:** [`PRD.md`](../../../PRD.md) — 이 계획은 PRD 9장의 2단계(4.1~4.3, 5장, 6장)를 구현한다. 진행표는 [`IMPL-PLAN.md`](../../../IMPL-PLAN.md).

## Global Constraints

- 앱 파일은 `index.html`, `style.css`, `script.js`, `questions.js` 4개뿐이다. 점검 코드를 별도 파일로 두지 않는다. Task 1에서 `tests.html`, `tests/`를 지운다.
- `file://`로 더블클릭해서 실행되어야 한다. ES 모듈(`import`/`export`), `fetch`, 외부 라이브러리·CDN을 쓰지 않는다.
  - `questions.js` 끝의 `if (typeof module !== "undefined") module.exports = QUESTIONS;`는 Node 점검용이며 브라우저에서는 실행되지 않는다.
- 완료 기준 점검: 터미널에서 `node script.js` → 마지막 줄 `PASS (n/n)`, 종료 코드 0. 실패하면 실패 항목과 `FAIL (...)`을 출력하고 종료 코드 1.
- 문항 데이터는 `textContent`/`href`로만 DOM에 넣는다. `innerHTML` 금지.
- 화면 문구는 PRD 그대로: "순위표에 기록되지 않음", "정답", "오답", "시간 초과", "다음", "결과 보기", "다시 하기", "처음으로", "틀린 문제 다시 풀기", "모두 맞혔어요", "그만두면 기록이 저장되지 않아요".
- 점수: 정답 1점, 힌트를 쓰고 맞히면 0.5점, 오답·시간 초과는 0점. 표시는 `8 / 10`, `7.5 / 10`. 다시 풀기 판은 `5문제 중 3개 맞힘`.
- 스피드: 문항마다 15초. 해설이 보이는 동안 타이머가 멈추고, [다음]을 누르면 15부터 다시 센다. 화면을 벗어나면 타이머를 정리한다.

- 틀린 문제 다시 풀기는 연습 모드에만 있다. 처음 점수는 바뀌지 않는다.
- 3단계 범위(localStorage, 순위표 화면, "이번 기록 n위")는 만들지 않는다.

```js
// ---- 자체 점검 (node script.js) ----
// 순수 함수와 실제 문항 데이터를 점검한다. 브라우저에서는 실행되지 않는다.

function runSelfChecks(questions) {
  const results = [];

  function check(name, fn) {
    try {
      fn();
      results.push({ name, ok: true });
    } catch (error) {
      results.push({ name, ok: false, message: error.message });
    }
  }

  function assert(condition, message) {
    if (!condition) throw new Error(message || "조건이 거짓입니다");
  }

  // JSON 문자열로 비교한다. 객체 키 순서도 같아야 한다.
  function assertEqual(actual, expected, message) {
    const a = JSON.stringify(actual);
    const e = JSON.stringify(expected);
    if (a !== e) throw new Error(`${message ? message + ": " : ""}기대값 ${e}, 실제값 ${a}`);
  }

  function makeQuestion(overrides) {
    return Object.assign({
      id: "science-99",
      category: "과학",
      question: "물의 화학식은?",
      choices: ["H₂O", "CO₂", "O₂", "NaCl"],
      answer: 0,
      explanation: "물 분자는 수소 원자 2개와 산소 원자 1개로 이루어진다.",
      source: { name: "테스트 출처", url: "https://example.com/water" }
    }, overrides);
  }

  // 카테고리마다 10개씩, 형식이 올바른 40문항
  function makeValidSet() {
    return CATEGORIES.flatMap((category, c) =>
      Array.from({ length: 10 }, (_, i) => makeQuestion({ id: `c${c}-${i}`, category }))
    );
  }

  // 한국사 12개 + 과학 3개
  function makePool() {
    const history = Array.from({ length: 12 }, (_, i) => makeQuestion({ id: `h-${i}`, category: "한국사" }));
    const science = Array.from({ length: 3 }, (_, i) => makeQuestion({ id: `s-${i}`, category: "과학" }));
    return history.concat(science);
  }

  // ---- shuffle ----
  check("shuffle: 원소는 그대로이고 순서만 바뀐다", () => {
    assertEqual(shuffle([1, 2, 3, 4, 5]).slice().sort(), [1, 2, 3, 4, 5]);
  });
  check("shuffle: 원본 배열을 바꾸지 않는다", () => {
    const original = [1, 2, 3, 4];
    shuffle(original);
    assertEqual(original, [1, 2, 3, 4]);
  });
  check("shuffle: random이 항상 0이면 Fisher–Yates 결과가 [2, 3, 4, 1]이다", () => {
    assertEqual(shuffle([1, 2, 3, 4], () => 0), [2, 3, 4, 1]);
  });
  check("shuffle: random이 1에 가까우면 순서가 그대로다", () => {
    assertEqual(shuffle([1, 2, 3, 4], () => 0.999), [1, 2, 3, 4]);
  });

  // ---- formatScore ----
  check("formatScore: 정수는 소수점 없이 쓴다", () => {
    assertEqual([formatScore(8), formatScore(0), formatScore(10)], ["8", "0", "10"]);
  });
  check("formatScore: 0.5 단위는 소수점 한 자리로 쓴다", () => {
    assertEqual([formatScore(7.5), formatScore(0.5)], ["7.5", "0.5"]);
  });

  // ---- validateQuestion / validateQuestions ----
  check("validateQuestion: 올바른 문항은 오류가 없다", () => {
    assertEqual(validateQuestion(makeQuestion()), []);
  });
  check("validateQuestion: 알 수 없는 카테고리를 잡는다", () => {
    assertEqual(validateQuestion(makeQuestion({ category: "수학" })).length, 1);
  });
  check("validateQuestion: 보기가 4개가 아니면 잡는다", () => {
    assertEqual(validateQuestion(makeQuestion({ choices: ["A", "B", "C"] })).length, 1);
  });
  check("validateQuestion: 같은 보기가 있으면 잡는다", () => {
    assertEqual(validateQuestion(makeQuestion({ choices: ["A", "B", "C", "A"] })).length, 1);
  });
  check("validateQuestion: 빈 보기를 잡는다", () => {
    assertEqual(validateQuestion(makeQuestion({ choices: ["A", "B", "C", " "] })).length, 1);
  });
  check("validateQuestion: answer가 0~3의 정수가 아니면 잡는다", () => {
    assertEqual(validateQuestion(makeQuestion({ answer: 4 })).length, 1);
    assertEqual(validateQuestion(makeQuestion({ answer: -1 })).length, 1);
    assertEqual(validateQuestion(makeQuestion({ answer: "0" })).length, 1);
  });
  check("validateQuestion: 빈 문제, 빈 해설, 빈 id를 잡는다", () => {
    assertEqual(validateQuestion(makeQuestion({ question: "" })).length, 1);
    assertEqual(validateQuestion(makeQuestion({ explanation: "  " })).length, 1);
    assertEqual(validateQuestion(makeQuestion({ id: "" })).length, 1);
  });
  check("validateQuestion: 출처가 없거나 URL이 https가 아니면 잡는다", () => {
    assertEqual(validateQuestion(makeQuestion({ source: undefined })).length, 2);
    assertEqual(validateQuestion(makeQuestion({ source: { name: "", url: "https://a.b" } })).length, 1);
    assertEqual(validateQuestion(makeQuestion({ source: { name: "출처", url: "http://a.b" } })).length, 1);
  });
  check("validateQuestions: 카테고리마다 10개인 올바른 40문항은 오류가 없다", () => {
    assertEqual(validateQuestions(makeValidSet()), []);
  });
  check("validateQuestions: id 중복을 잡는다", () => {
    const set = makeValidSet();
    set[1].id = set[0].id;
    const errors = validateQuestions(set);
    assertEqual(errors.length, 1);
    assert(errors[0].includes("중복"), errors[0]);
  });
  check("validateQuestions: 전체 개수와 카테고리별 개수를 잡는다", () => {
    assertEqual(validateQuestions(makeValidSet().slice(1)).length, 2); // 한국사 9개, 전체 39개
  });
  check("validateQuestions: 각 문항의 오류도 함께 모은다", () => {
    const set = makeValidSet();
    set[0].answer = 9;
    assertEqual(validateQuestions(set).length, 1);
  });

  // ---- prepareQuestion / buildRound ----
  check("prepareQuestion: 보기를 섞고 정답 위치를 정답 보기 내용에 맞춰 다시 계산한다", () => {
    const prepared = prepareQuestion(makeQuestion({ choices: ["A", "B", "C", "D"], answer: 0 }), () => 0);
    assertEqual(prepared.choices, ["B", "C", "D", "A"]);
    assertEqual(prepared.answer, 3);
  });
  check("prepareQuestion: 원본 문항을 바꾸지 않는다", () => {
    const q = makeQuestion({ choices: ["A", "B", "C", "D"], answer: 1 });
    prepareQuestion(q, () => 0);
    assertEqual([q.choices, q.answer], [["A", "B", "C", "D"], 1]);
  });
  check("prepareQuestion: 무작위로 섞어도 정답 보기 내용은 그대로다", () => {
    const q = makeQuestion({ choices: ["A", "B", "C", "D"], answer: 2 });
    for (let i = 0; i < 20; i++) {
      const prepared = prepareQuestion(q);
      assertEqual(prepared.choices[prepared.answer], "C");
    }
  });
  check("buildRound: 고른 카테고리 문항만 최대 10개 고른다", () => {
    const round = buildRound(makePool(), "한국사");
    assertEqual(round.length, 10);
    assert(round.every(q => q.category === "한국사"), "다른 카테고리 문항이 섞임");
    assertEqual(new Set(round.map(q => q.id)).size, 10);
  });
  check("buildRound: 문항이 10개보다 적으면 있는 만큼만 고른다", () => {
    assertEqual(buildRound(makePool(), "과학").length, 3);
  });
  check("buildRound: 모든 문항의 정답 보기 내용이 원본과 같다", () => {
    const pool = makePool();
    buildRound(pool, "한국사").forEach(q => {
      const original = pool.find(p => p.id === q.id);
      assertEqual(q.choices[q.answer], original.choices[original.answer], q.id);
    });
  });

  // ---- 여기에 다음 점검을 추가한다 ----

  // ---- 실제 문항 데이터 ----
  CATEGORIES.forEach(category => {
    check(`${category}: 10문항이 모두 형식 검사를 통과한다`, () => {
      const items = questions.filter(q => q.category === category);
      assertEqual(items.length, QUESTIONS_PER_ROUND, `${category} 문항 수`);
      assertEqual(items.flatMap(validateQuestion), [], `${category} 형식 오류`);
    });
  });
  check("QUESTIONS 전체가 validateQuestions를 통과한다 (40문항, id 중복 없음)", () => {
    assertEqual(validateQuestions(questions), []);
  });

  return results;
}

// 실패 항목과 요약만 출력한다. 실패가 있으면 종료 코드를 1로 한다.
function printSelfCheckResults(results) {
  results.filter(r => !r.ok).forEach(r => console.log(`✗ ${r.name} — ${r.message}`));
  const passed = results.filter(r => r.ok).length;
  const failed = results.length - passed;
  console.log(`${failed ? "FAIL" : "PASS"} (${passed}/${results.length})`);
  if (failed) process.exitCode = 1;
}

// ---- 실행 ----
// 브라우저에서는 앱을 띄우고, Node(node script.js)에서는 자체 점검만 하고 끝낸다.
if (typeof window === "undefined") {
  printSelfCheckResults(runSelfChecks(require("./questions.js")));
} else {
  initApp();
}
```

```js
// 틀린 문항만 골라 문제 순서와 보기를 다시 섞은 판을 만든다. questions에는 원본 문항을 넘긴다.
```
